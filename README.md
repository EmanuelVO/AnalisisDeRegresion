# AnalisisDeRegresion

1. Considera la base de datos del archivo “kc_house_data.csv” donde el objetivo es el de pronosticar el precio de una casa a partir de diversas variables que la definen (como número de habitaciones, baños, etc.).

2. Selecciona variables independientes adecuadas a partir del archivo arriba mencionado.

Se eliminaron las variables ‘id’ y ‘date’. 

3. Construye un modelo de regresión lineal múltiple mediante matrices para pronosticar el precio de una casa.

Asegúrate de eliminar aquellas variables que no sean relevantes y comenta sobre la bondad del ajuste y la ecuación final resultante, comparando contra el reporte automatizado disponible.
